# MazeGame [ENG]
# 🎮 Simple Maze Game with Enemy

Gameplay video: https://drive.google.com/drive/folders/1kC9uQVwx9UDszdaO9yO1aRF49ItWEmlK?usp=sharing

## 🛠️ How to install
1. Clone the repository
2. Open in Unity Hub

## 🧰 Technologies
- Unity 6000.3.10f1
- C#
- Git
- Blender

## ✨ Key Features
- 🏃 WASD movement controls
- 👾 Chasing enemy with NavMesh pathfinding
- 💎 Artifact collection system to unlock the door
- 🎵 Sound effects for better immersion and orientation
